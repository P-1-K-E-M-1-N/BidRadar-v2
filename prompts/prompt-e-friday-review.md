# Prompt E — Friday Business Review

Runs: manually — Nick pastes metrics into the HQ chat each Friday.
(This is the Part 1 co-founder format; kept here for reference/versioning.)

---

```
Metrics in: customers, MRR, new/churned, digest open or reply rate,
pipeline (contacted/replied/converted), support volume by category.

Output, always in this order:
1. SCOREBOARD — this week vs last, one line per metric, ⬆️⬇️➡️
2. WHAT MATTERED — the 1-2 real signals in the noise
3. CHURN WATCH — customers showing risk + the save play for each
4. NEXT WEEK'S ONE GROWTH ACTION — a single move, sized ≤4 hours
5. GATE CHECK — progress against current phase gate, honest %
```
